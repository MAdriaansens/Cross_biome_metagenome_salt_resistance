The aim of this research is to infer the changes in osmotic adaptations and salinity resistance genes. 
To achieve this aim the following objectives are set:

1. Manually curate a database of SRR ids, with matching metadata
2. Create a Protein DB by using Protein-based searches against the GTDB232 Database of Archaea/Bacteria and Eukarya
3. Diamond BLAST each SRR against the protein DB
4. Parse this Diamond BLAST data
5. Infer and visualize this data
